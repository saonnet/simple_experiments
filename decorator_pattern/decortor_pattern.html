Very simple decorator pattern implemented in js

  • Text formatting isn't ideal use case of decorator pattern but this is serves fine for an example.
  • Classes:
    • Base class: Text
    • Base render class: PlainText, this just returns the text to be rendered as string.
    • Decorator classes:
      • BoldText: Holds an instance of Text class, calls the getText() method on the decorated instance and decorates(adds) bold formatting to it.
      • ItalicText: Holds an instance of Text class, calls the getText() method on the decorated instance and decorates(adds) italic formatting to it.
      • UnderlineText: Holds an instance of Text class, calls the getText() method on the decorated instance and decorates(adds) underline formatting to it.
